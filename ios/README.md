# Smart Вільногірськ — iOS-додаток

Нативна оболонка (SwiftUI + WKWebView) навколо сайту [vilnohirsk.online](https://vilnohirsk.online) для особистого користування — без App Store.

## Що вміє

- Повноекранний перегляд сайту без адресного рядка Safari — виглядає як звичайний додаток.
- Потягнути вниз — оновити сторінку (pull-to-refresh).
- Свайп вліво/вправо — назад/вперед по історії.
- Зовнішні посилання (Telegram, Viber, дзвінки `tel:`, чужі сайти) відкриваються у відповідних додатках, а сам додаток залишається на сайті.
- Екран «Немає з'єднання» з кнопкою «Оновити», якщо інтернет зник.
- Обране, кеш та інші дані сайту (localStorage) зберігаються між запусками.
- Іконка додатка — та сама, що й у PWA.

## Як запустити на своєму iPhone

1. Склонуйте репозиторій на Mac (або завантажте ZIP цієї гілки) і відкрийте
   **`ios/SmartVilnohirsk.xcodeproj`** в Xcode (потрібен Xcode 16 або новіший).
2. У навігаторі зліва клацніть корінь проєкту **SmartVilnohirsk** → вкладка
   **Signing & Capabilities**:
   - **Team** → виберіть свій Apple ID (якщо його немає — Xcode → Settings → Accounts → «+» → увійдіть своїм Apple ID; з'явиться *Personal Team*).
   - Якщо Xcode скаржиться на Bundle Identifier — змініть його на щось унікальне, напр. `online.vilnohirsk.smart.denys`.
3. Підключіть iPhone кабелем (або по Wi-Fi) і виберіть його у списку пристроїв угорі.
4. Натисніть **Run** (▶ або Cmd+R).
5. Перший раз iPhone попросить довіритися розробнику:
   **Налаштування → Основні → VPN і керування пристроєм → ваш Apple ID → Довіряти**.
   Також має бути ввімкнено **Режим розробника** (Налаштування → Конфіденційність і безпека → Режим розробника) — iPhone сам запропонує це при першому запуску.

## Обмеження безкоштовного Apple ID

- Підпис додатка діє **7 днів** — потім він перестає запускатися, і треба ще раз натиснути Run в Xcode (дані додатка при цьому зберігаються).
- Не більше 3 додатків з особистим підписом одночасно на пристрої.
- З платним акаунтом розробника ($99/рік) підпис діє рік, і можна публікуватися в App Store / TestFlight.

## Відомі особливості

- **Push-сповіщення сайту (Firebase Web Push) у додатку не приходять** — вони працюють лише в Safari/PWA. Для нативних пушів потрібна окрема інтеграція Firebase iOS SDK (можна додати пізніше).
- Фото до оголошень додаються через стандартний вибір із галереї/камери — для камери в проєкті вже прописаний дозвіл `NSCameraUsageDescription`.

## Структура

```
ios/
├── SmartVilnohirsk.xcodeproj/     # проєкт Xcode
└── SmartVilnohirsk/
    ├── SmartVilnohirskApp.swift   # точка входу
    ├── ContentView.swift          # екран: WebView + лоадер + офлайн-екран
    ├── WebView.swift              # WKWebView: навігація, зовнішні посилання, pull-to-refresh
    └── Assets.xcassets/           # іконка додатка (з apple-touch-icon сайту)
```
