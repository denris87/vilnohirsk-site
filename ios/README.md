# Smart Вільногірськ — iOS-додаток

Нативний SwiftUI-додаток у стилі «Дії»: світла тема, білі картки, кольорові акценти.
Усі розділи сайту [vilnohirsk.online](https://vilnohirsk.online) — нативними екранами,
дані тягнуться з тих самих API та YAML-файлів, що використовує сайт.
**Сайт не змінено — весь додаток живе у папці `ios/`.**

## Екрани (16)

| Екран | Дані |
|---|---|
| 🏠 Головна | час, погода (Open-Meteo), курс валют (Приват → Mono → НБУ), пальне (`data/fuel.yaml`), статус світла, стрічка «Зараз у місті» |
| 🚆 Електрички + Потяги | trains API + затримки з `data/delays.yaml`, повний розклад зупинок |
| 🚌 Автобуси | buses API, розклади за напрямками та зупинками |
| 🚗 Попутники | rides API, водії/пасажири |
| 💡 Світло | `data/svitlo.yaml`, черги ЦЕК/ДТЕК |
| 🧾 Комуналка | alerts API — повідомлення служб і новини |
| 🗺️ Карта міста | MapKit + `data/places.yaml`, фільтр за категоріями |
| 📒 Довідник | phonebook API + швидкі 101/102/103/104, пошук |
| 🛒 Барахолка | Google Sheets (та сама таблиця, що на сайті), категорії, фото, дзвінок |
| 🏠 Нерухомість | Google Sheets, продаж/оренда |
| 🛍️ Шопінг | promos API (акції тижня) + shops API (магазини) |
| 💼 Робота | jobs API + вакансії з форм сайту |
| 🔍 Загублено | Google Sheets, загублено/знайдено |
| 🎭 Події | events.json (афіші) |
| 🇺🇦 ЗСУ | volunteers API (збори з прогресом, банка, копіювання картки) + phoenix API (зниклі безвісти) |
| 💬 Зв'язок | Telegram/Facebook/Instagram міста + вбудований сайт |

Додавання оголошень (кнопки «+ Додати») відкриває сайт у вбудованому вікні —
форми та модерація лишаються на сайті.

## Як запустити на своєму iPhone

1. Склонуйте цю гілку на Mac і відкрийте **`ios/SmartVilnohirsk.xcodeproj`** в Xcode (16+).
2. Проєкт **SmartVilnohirsk** → **Signing & Capabilities** → **Team** — ваш Apple ID
   (Personal Team). Якщо лається на Bundle ID — допишіть щось своє, напр. `online.vilnohirsk.smart.denys`.
3. Виберіть свій iPhone у списку пристроїв → **Run** (Cmd+R).
4. Перший запуск: iPhone → Налаштування → Основні → VPN і керування пристроєм →
   довіритися розробнику; увімкнути «Режим розробника», якщо запропонує.

Безкоштовний Apple ID: підпис діє 7 днів, потім ще раз Run (дані зберігаються);
до 3 таких додатків на пристрої.

## Структура

```
ios/
├── SmartVilnohirsk.xcodeproj/
└── SmartVilnohirsk/
    ├── SmartVilnohirskApp.swift   # точка входу (світла тема)
    ├── Theme.swift                # дизайн-система «Дії»: кольори, картки, шрифти
    ├── Components.swift           # картки, чипи, фото, стани завантаження
    ├── Api.swift                  # HTTP + кеш, міні-парсери YAML і CSV
    ├── Models.swift               # моделі всіх розділів + завантаження даних
    ├── ContentView.swift          # головний екран: шапка, сервіси, банер ЗСУ
    ├── TransportScreens.swift     # електрички, потяги, автобуси, попутники
    ├── CityScreens.swift          # світло, комуналка, карта, довідник
    ├── MarketScreens.swift        # барахолка, нерухомість, шопінг, робота, загублено
    ├── CommunityScreens.swift     # події, ЗСУ, зв'язок + вбудований сайт
    ├── WebView.swift              # WKWebView-обгортка сайту (для форм)
    └── Assets.xcassets/           # іконка додатка
```

## Відомі особливості

- Push-сповіщення сайту (Firebase Web Push) у додаток не приходять — вони працюють
  лише у Safari/PWA. Для нативних пушів потрібна інтеграція Firebase iOS SDK.
- Деякі API міста (Railway) «засинають» — перший запит може тривати кілька секунд;
  потягніть список вниз, щоб оновити.
